SecureCorp VAPT Assessment

# About This Project

This project documents a vulnerability assessment and penetration testing exercise performed in an authorized Metasploitable 2 lab environment.

The assessment was carried out using Kali Linux to identify open services, investigate vulnerabilities, and validate selected findings through controlled testing.

# Target

- Target: Metasploitable 2
- IP Address: 192.168.201.135
- Testing Machine: Kali Linux
- Environment: Authorized lab environment

# Tools Used

- Nmap
- Nikto
- cURL
- Enum4linux
- SMB tools
- Metasploit Framework

# Testing Performed

- Host connectivity testing
- Port and service enumeration
- Web server enumeration
- Information exposure testing
- FTP and Telnet testing
- SMB enumeration
- Password policy enumeration
- Samba vulnerability research
- Controlled exploitation
- Privilege verification
- Post-exploitation verification
